📘 About the Strategy

The Magic Formula is an investment approach that ranks companies based on two key factors:
Return on Capital (ROC) – Measures how efficiently a company generates profits from its capital.
Earnings Yield (EY) – Indicates how cheap or undervalued a company is compared to its earnings.
By combining these metrics, the formula helps investors find quality companies at bargain prices, providing a systematic, rules-based investment approach.


🚀 Features

Fetches financial data for companies listed on NSE/BSE.

Calculates key Magic Formula metrics:
Return on Capital (ROC)
Earnings Yield (EY)
Ranks companies based on Magic Formula criteria.
Displays a list of top companies to invest in according to the strategy.

Optional features:
Historical performance tracking
Stock detail insights
Export rankings to CSV


💻 Tech Stack

Frontend: React.js, Bootstrap/Tailwind CSS
Backend: Flask (Python)
Database: SQLite / MySQL (optional)
APIs: Yahoo Finance, NSE/BSE data sources
Libraries: Pandas, NumPy, yfinance, requests


⚡ Installation

Clone the repository:
git clone https://github.com/your-username/magic-formula.git
cd magic-formula

Install backend dependencies:
pip install -r requirements.txt

Start the Flask backend:
python app.py

Start the React frontend:
cd frontend
npm install
npm start


🧩 Usage

Open the frontend in your browser (usually at http://localhost:3000).
The dashboard will show a list of top-ranked companies based on the Magic Formula.
You can filter, search, and view company-specific details.
